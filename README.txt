## About the Project
Crop Production Predictor is a machine learning web application built with Streamlit. It predicts crop yield based on agricultural and environmental features entered by the user.

The application uses pre-trained machine learning models to generate predictions without training the models again.

## Technologies Used
- Python
- Streamlit
- Joblib
- Scikit-learn and other libraries required by the saved models

## Machine Learning Models
The project includes pre-trained models such as:
- Random Forest
- XGBoost
- LightGBM
- CatBoost
- K-Nearest Neighbors (KNN)

## Features
- Simple and interactive web interface
- Crop yield prediction using pre-trained models
- Supports multiple crops
- You can choose the model of your own choice from the list for the prediction
- Easy access through a web browser

## How to Run Locally

1. Install Anaconda and ensure Streamlit is installed in your environment.
2. Open Anaconda Prompt.
3. Navigate to the project folder using the `cd` command. For example:

   `cd "C:\Anaconda\Scripts\Crop Production Predictor"`

4. Run the application:

   `streamlit run app.py`

5. It should open automatically, if it's not openining automatically then Open the local URL displayed in the terminal in your web browser.
